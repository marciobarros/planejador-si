# Planejador de projetos de SI

(ok) Funcionalidade: nome e lista de transações

(ok) Transação: nome

(pendente) Grupamento de dados: nome, tipo (ILF ou EIF) e lista de RET

(pendente) RET: nome e lista de DET

(pendente) DET em grupamento de dados: nome, RET referenciado pelo DET

(pendente) Detalhamento das transações: tipo (EI, EO ou EQ), DETs, grupamentos de dados atualizados, grupamentos de dados consultados

(pendente) DET em transação: nome

Funcionalidades:

* cálculo do número de pontos por função

* geração de cronograma
